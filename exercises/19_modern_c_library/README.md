# Modern C Library

Run an exercise with:

```sh
./clings run 01_noreturn
```

| Exercise | Objective |
| --- | --- |
| `01_noreturn` | Declare a function that never returns and observe its exit status. |
| `02_tgmath` | Use sqrt with both double and float arguments through tgmath.h. |
| `03_atexit` | Register a cleanup function with atexit. |
| `04_atomic_flag` | Use atomic_flag as a simple test-and-set lock. |
