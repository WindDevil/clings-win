# 文件 I/O

运行练习：

```sh
./clings run 01_fprintf_fscanf
```

| 练习 | 目标 |
| --- | --- |
| `01_fprintf_fscanf` | 把格式化数据写入文件，再读回来。 |
| `02_fgets_fputs` | 逐行复制文本文件。 |
| `03_getc_putc_ungetc` | 先看一眼字符，再把它放回流里。 |
| `04_fseek_ftell` | 定位到某个字节偏移，并报告结果位置。 |
| `05_fflush_setvbuf` | 配置全缓冲并刷新流。 |
| `06_binary_random_access` | 从二进制文件里读出指定的结构体记录。 |
| `07_buffered_output_memory` | 把 malloc、setvbuf、输出、fclose 和 free 串起来用。 |
