# File I/O

Run an exercise with:

```sh
./clings run 01_fprintf_fscanf
```

| Exercise | Objective |
| --- | --- |
| `01_fprintf_fscanf` | Write formatted data to a file and read it back. |
| `02_fgets_fputs` | Copy a text file line by line. |
| `03_getc_putc_ungetc` | Peek at a character and put it back into the stream. |
| `04_fseek_ftell` | Seek to a byte offset and report the resulting position. |
| `05_fflush_setvbuf` | Configure full buffering and flush a stream. |
| `06_binary_random_access` | Read a specific struct record from a binary file. |
| `07_buffered_output_memory` | Combine malloc, setvbuf, output, fclose, and free. |
