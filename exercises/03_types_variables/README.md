# Types, Variables, and Storage

Run an exercise with:

```sh
./clings run 01_integer_types
```

| Exercise | Objective |
| --- | --- |
| `01_integer_types` | Use sizeof, CHAR_BIT, INT_MIN, and INT_MAX correctly. |
| `02_signed_unsigned` | Avoid the usual arithmetic conversion trap when comparing. |
| `03_overflow` | Understand modulo wrap and avoid signed integer overflow. |
| `04_floating_point` | Compare floating-point values with an epsilon. |
| `05_char_ascii` | Work with char values and the ctype classification functions. |
| `06_storage_scope` | Observe the lifetime of a static variable and block scope. |
| `07_qualifiers` | Use const, volatile, extern, auto, and register. |
| `08_stdbool_stddef` | Use bool and size_t from the standard headers. |
| `09_long_double` | Use long double and compare its precision with double. |
| `10_octal_constants` | Recognize that a leading zero means base 8. |
| `11_char_signedness` | Use signed char and unsigned char explicitly when the sign matters. |
| `12_integer_promotions` | See that char operands are promoted to int in arithmetic expressions. |
