# 类型、变量与存储

运行练习：

```sh
./clings run 01_integer_types
```

| 练习 | 目标 |
| --- | --- |
| `01_integer_types` | 正确使用 sizeof、CHAR_BIT、INT_MIN 和 INT_MAX。 |
| `02_signed_unsigned` | 比较时避开寻常算术转换的陷阱。 |
| `03_overflow` | 理解取模回绕，并避开有符号整数溢出。 |
| `04_floating_point` | 用 epsilon 比较浮点数。 |
| `05_char_ascii` | 处理 char 值，并使用 ctype 的字符分类函数。 |
| `06_storage_scope` | 观察静态变量的生存期与块作用域。 |
| `07_qualifiers` | 使用 const、volatile、extern、auto 和 register。 |
| `08_stdbool_stddef` | 使用标准头文件里的 bool 和 size_t。 |
| `09_long_double` | 使用 long double，并与 double 比较精度。 |
| `10_octal_constants` | 认识到前导 0 表示八进制。 |
| `11_char_signedness` | 符号性重要时，明确使用 signed char 和 unsigned char。 |
| `12_integer_promotions` | 看清 char 操作数在算术表达式里会提升为 int。 |
