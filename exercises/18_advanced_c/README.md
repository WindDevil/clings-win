# Advanced C

Run an exercise with:

```sh
./clings run 01_variadic
```

| Exercise | Objective |
| --- | --- |
| `01_variadic` | Read a variable number of int arguments with va_list. |
| `02_setjmp_longjmp` | Use non-local jumps for a simple error path. |
| `03_pthreads` | Create threads and protect shared state with a mutex. |
| `04_atomics` | Use atomic_int for lock-free counter updates. |
| `05_generic` | Choose an expression based on the type of a value. |
| `06_static_assert` | Use _Static_assert to enforce assumptions at compile time. |
| `07_align` | Query and request alignment. |
| `08_anonymous_union` | Access anonymous union members directly through the outer struct. |
| `09_thread_local` | Use _Thread_local to give each thread its own object. |
| `10_complex` | Use double complex, I, conj, creal, and cimag. |
| `11_signal` | Install a signal handler and use a sig_atomic_t flag. |
| `12_stack_frame` | Observe that nested function calls use distinct activation records. |
