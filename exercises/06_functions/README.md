# Functions and Scope

Run an exercise with:

```sh
./clings run 01_declaration_definition
```

| Exercise | Objective |
| --- | --- |
| `01_declaration_definition` | Use a forward declaration and an internal helper. |
| `02_parameters_return` | Return values through parameters and clamp a range. |
| `03_recursion` | Write recursive functions with correct base cases. |
| `04_static_inline` | Use static functions and file-scope state. |
| `05_void_and_return` | Return early from a void function and return values from int functions. |
| `06_tail_recursion` | Rewrite a recursive sum using an accumulator. |
| `07_main_return_value` | Return a defined success or failure status from a program. |
