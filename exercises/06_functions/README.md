# 函数与作用域

运行练习：

```sh
./clings run 01_declaration_definition
```

| 练习 | 目标 |
| --- | --- |
| `01_declaration_definition` | 使用前置声明和内部辅助函数。 |
| `02_parameters_return` | 通过参数返回结果，并把范围夹紧。 |
| `03_recursion` | 写出基准情形正确的递归函数。 |
| `04_static_inline` | 使用 static 函数和文件作用域状态。 |
| `05_void_and_return` | 在 void 函数里提前 return，在 int 函数里返回值。 |
| `06_tail_recursion` | 用累加器改写递归求和。 |
| `07_main_return_value` | 让程序返回明确表示成功或失败的状态码。 |
