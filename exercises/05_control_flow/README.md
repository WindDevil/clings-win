# 控制流

运行练习：

```bat
clings.cmd run 01_if_else
```

| 练习 | 目标 |
| --- | --- |
| `01_if_else` | 写出清晰的条件分支。 |
| `02_switch_case` | 使用有意为之的贯穿和 default 分支。 |
| `03_loops` | 把循环边界和累加器写对。 |
| `04_break_continue` | 用 break 提前结束，用 continue 跳过一轮。 |
| `05_while_do_while` | 区分入口条件循环和出口条件循环。 |
| `06_semicolon_pitfalls` | 避免误用分号提前结束 if 或循环。 |
| `07_dangling_else` | 用花括号让 else 绑定到预期的 if。 |
