# Control Flow

Run an exercise with:

```sh
./clings run 01_if_else
```

| Exercise | Objective |
| --- | --- |
| `01_if_else` | Write clear conditional branches. |
| `02_switch_case` | Use intentional fallthrough and a default case. |
| `03_loops` | Get loop bounds and accumulators right. |
| `04_break_continue` | Use break to stop early and continue to skip one iteration. |
| `05_while_do_while` | Distinguish entry-condition and exit-condition loops. |
| `06_semicolon_pitfalls` | Avoid accidentally ending an if or loop with a semicolon. |
| `07_dangling_else` | Use braces to make else bind to the intended if. |
